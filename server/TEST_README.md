# Testing Guide for Grafana TRMNL Plugin Server

This directory contains the Jest unit tests for the Grafana TRMNL Plugin Server.

## Test Structure

### Test Files
- `__tests__/server.test.ts` - Main Jest suite for server rendering and HTML output
- `test_data/` - JSON fixtures for different panel types
- `package.json` - Contains the `test` script and Jest dependencies

### Test Data Files
The tests use JSON fixtures stored in `test_data/` to simulate Grafana panel data:

- `stat_panel_data.json`
- `gauge_panel_data.json`
- `timeseries_panel_data.json`
- `multi_series_timeseries_data.json`
- `bar_gauge_panel_data.json`
- `piechart_panel_data.json`
- `table_panel_data.json`

## Running Tests

### Prerequisites
Install dependencies:
```bash
npm install
```

### Run Tests

#### Option 1: Using npm
```bash
npm test
```

#### Option 2: Using Jest directly
```bash
npx jest --runInBand
```

#### Option 3: Run a single test file
```bash
npx jest __tests__/server.test.ts --runInBand
```

## What the Tests Cover

### Panel Types Tested
- ✅ Stat panels
- ✅ Gauge panels
- ✅ Timeseries panels
- ✅ Multi-series timeseries panels
- ✅ Bar gauge panels
- ✅ Piechart panels
- ✅ Table panels

### Response Modes Tested
- ✅ JSON output
- ✅ Full HTML output

### Testing Strategy
- Uses Jest with TypeScript support via `ts-jest`
- Loads fixture data from `test_data/`
- Validates HTML output generated by `htmlUtils.tsx`
- Ensures rendering logic matches expected panel behavior

## Adding New Tests

1. Add a new fixture file to `test_data/` for the panel scenario.
2. Extend `__tests__/server.test.ts` with a new Jest test case.
3. Mock or load the fixture and assert the generated HTML includes the expected chart elements.

## Example Jest Command

```bash
npm test -- --runInBand
```

> Note: `npm test` is configured to run `jest --runInBand` in this repository.
